# MapCast — карта WoW Forever на телефоне или планшете

Аддон и программа-компаньон для ПК. Вместе они показывают живую карту на
телефоне или планшете, без открытой карты в игре: твою позицию, направление
взгляда и группу. Если установлен [OpenMap](https://github.com/openmap-world/openmap),
карта на телефоне бесшовная, как у него: весь Азерот одним полотном.

```
WoW (аддон MapCast)  ──пиксели в углу экрана──▶  компаньон на ПК  ──Wi-Fi──▶  браузер телефона
```

Аддоны WoW не могут выходить в сеть: в их Lua просто нет таких функций.
Поэтому аддон рисует в левом верхнем углу экрана тонкую полоску цветных
квадратиков (768 × 6 пикселей). Компаньон считывает её с экрана, декодирует и
раздаёт карту по домашнему Wi-Fi. Картинки карт он берёт прямо из файлов
установленной игры и из папки аддона OpenMap.

## Что уже работает

- Бесшовная карта мира в стиле OpenMap: плавный зум от улиц до всего Азерота.
  Издалека карта мира, ближе карты континентов, ещё ближе сшитые зоны OpenMap.
  Названия континентов на языке игры.
- Кнопка с глобусом переключает карту мира и карту текущей зоны. В подземелье
  телефон сам показывает карту подземелья.
- Точки полётов твоей фракции: изученные в цвете, остальные серые. Пунктиром
  показаны пути между изученными точками, то есть куда можно улететь.
- Причалы кораблей и цеппелинов и их маршруты пунктиром (синие у Альянса,
  красные у остальных).
- Входы в подземелья и рейды. Уровни раскрашены по уровню персонажа, как задания
  в игре; при сильном приближении видны названия.
- Нажми на значок, чтобы открыть карточку: точка полёта (изучена или нет), куда
  идёт корабль, подземелье с уровнями и боссами. Кнопка со слоями включает и
  выключает полёты, транспорт и подземелья.
- Карта текущей зоны из файлов игры, с открытыми областями (туман войны), как в игре.
- Стрелка персонажа с направлением взгляда, плавное движение.
- Группа и рейд: точки цвета класса с именами.
- Слежение за персонажем, режим «карта поворачивается по взгляду», жесты
  (перетаскивание, щипок, двойной тап), полноэкранный режим.
- Доступ по токену или QR-коду.

Дальше в плане:
- Значки HandyNotes, TomTom, GatherMate2, Questie и RestedXP Guide, квестовые точки.
- Затемнение неоткрытых зон на карте мира, как в OpenMap.

## Установка

### 1. Аддон

Скопируй папку `addon/MapCast` в
`World of Warcraft\_forever_\Interface\AddOns\MapCast`.

В игре проверь, что в левом верхнем углу появилась цветная полоска.

Для бесшовной карты мира нужен аддон OpenMap в той же папке AddOns. Компаньон
найдёт его сам. Если OpenMap лежит в другом месте, укажи путь через `--openmap`.
Из папки OpenMap компаньон берёт и точки полётов, маршруты кораблей и входы в
подземелья.

Аддон сам запоминает изученные точки полётов, когда ты открываешь карту у
распорядителя полётов. Те, что уже запомнил OpenMap, он берёт сразу.

При обновлении аддона замени папку целиком и сделай `/reload` или перезайди.

### 2. Компаньон (на том же ПК, где запущена игра)

Нужен Python 3.10 или новее ([python.org](https://www.python.org/downloads/),
при установке отметь «Add python.exe to PATH»).

```bash
cd companion
```

```bash
python -m pip install -r requirements.txt
```

Запуск: дважды кликни `companion\run.bat` или выполни:

```bash
python run.py
```

При первом запуске Windows спросит про брандмауэр: разреши доступ для
**частных сетей**, иначе телефон не подключится. Откроется страница с QR-кодом:
отсканируй её телефоном (он должен быть в той же Wi-Fi сети). Токен и адрес
также печатаются в окне компаньона.

Компаньон сам находит папку WoW. Если не нашёл, карта будет сеткой без картинки,
и путь нужно указать вручную:

```bash
python run.py --wow "C:\Program Files (x86)\World of Warcraft"
```

При первом запуске с OpenMap компаньон около 10 секунд готовит тайлы карты мира.
Потом он берёт их из кэша.

### Настройки игры

- Режим окна: «Полноэкранный в окне» или «В окне». Окно игры должно быть видно,
  а левый верхний угол ничем не закрыт.
- Гамма, яркость и контраст — по умолчанию, иначе цвета полоски искажаются.

## Команды аддона

| Команда | Что делает |
|---|---|
| `/mapcast` | состояние |
| `/mapcast on` / `off` | показать или скрыть полоску |
| `/mapcast cell 4` | размер квадратика в пикселях (1–8, по умолчанию 3) |
| `/mapcast cols 256`, `rows 2` | размер полоски в квадратиках |
| `/mapcast rate 0.1` | как часто обновлять данные, в секундах |
| `/mapcast diag` | проверить, что игра даёт читать аддону, и сколько точек полётов изучено |

## Параметры компаньона

| Параметр | Что делает |
|---|---|
| `--wow ПУТЬ` | папка WoW (та, где лежит `.build.info`) |
| `--openmap ПУТЬ` | папка аддона OpenMap, если она не в AddOns игры |
| `--port 8765` | порт веб-сервера |
| `--fps 30` | сколько раз в секунду читать экран |
| `--sim` | симуляция игры без WoW, чтобы проверить телефон |
| `--no-browser` | не открывать страницу с QR на ПК |
| `-v` | подробный лог |

Токен хранится в `%APPDATA%\MapCast\config\config.json`, кэш карт — в
`%LOCALAPPDATA%\MapCast\cache`. Чтобы сменить токен, удали `config.json`.

## Если что-то не так

Подсказка появляется прямо на экране телефона:

| Сообщение | Что сделать |
|---|---|
| Окно WoW не найдено | запусти игру, не сворачивай её |
| Не вижу полоску аддона | `/mapcast on`, проверь, что аддон включён и угол окна не закрыт |
| Цвета искажены | гамма, яркость и контраст в игре — по умолчанию |
| Нет связи с компаньоном | компаньон запущен? телефон в той же Wi-Fi сети? брандмауэр разрешён? |
| Игра не даёт координаты | в подземельях, рейдах и на полях боя Blizzard скрывает позицию от аддонов |
| Компаньон не нашёл OpenMap | установи OpenMap или запусти компаньон с `--openmap "путь"`; без него на карте мира нет зон |

Чтобы экран планшета не гас, увеличь время отключения экрана в его настройках.

## Ограничения и риски

- В подземельях и рейдах позиции нет: это ограничение API игры для всех аддонов.
- Надписи на сшитых зонах английские: OpenMap запекает их из английского
  клиента. В игре с русским клиентом OpenMap рисует зоны из русских карт, так
  что надписи в игре и на телефоне могут отличаться.
- Названия точек полётов, зон и подземелий на языке игры, а имена боссов и
  маршруты кораблей — по-английски, как в данных OpenMap.
- WoW Forever показывает все точки полётов как открытые, поэтому изученными
  считаются только те, что аддон или OpenMap видели у распорядителя полётов.
- Компаньон только читает картинку с экрана, как программа для стрима. Он не
  нажимает клавиши и не читает память игры. Но прямого разрешения Blizzard на
  чтение данных из пикселей нет, так что небольшой риск остаётся.

## Для разработки

```bash
cd companion
```

```bash
python -m pytest
```

Тесты запускают настоящий Lua-код аддона в LuaJIT с имитацией API WoW,
рендерят полоску в пиксели и проверяют весь путь до декодера. Ещё они читают
синтетическое хранилище CASC, собирают карту и проверяют тайлы карты мира из
маленькой копии папки OpenMap. Если задать переменную `OPENMAP_DIR` с путём к
папке OpenMap, тест ещё разберёт его настоящие данные о полётах и подземельях.
Протокол описан в
[docs/PROTOCOL.md](docs/PROTOCOL.md).

Симуляция с бесшовной картой (нужна папка OpenMap, например из его репозитория):

```bash
python run.py --sim --openmap "путь\к\OpenMap"
```
